Privacy Policy

Christopher GWS CLI
Last updated: October 22, 2026

1. Who we are

Christopher GWS CLI ("the app") is a private command-line tool operated by Christopher, Surabaya, Indonesia, for use with his own Google Workspace account.

2. Information the app accesses

With the user's permission, granted through Google's OAuth consent screen, the app may access Google user data such as Gmail messages, Google Drive files, Google Calendar events and Google Sheets content, limited to the scopes the user approves.

3. How the information is used

Google user data is used only to perform the actions the user requests from the command line, such as listing, reading, searching, creating or updating emails, files, events and spreadsheets. It is not used for advertising, profiling or any other purpose.

4. Storage and security

The app runs on the user's own computer. OAuth tokens and any data retrieved are stored locally on that computer only. The app does not operate its own servers and does not upload Google user data anywhere else.

5. Sharing

Google user data is never sold, rented or shared with third parties, and is not transferred to anyone except as required by law.

6. Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access and deleting data

You can revoke the app's access at any time at myaccount.google.com/permissions. Deleting the app's local configuration folder removes all stored tokens and data from your computer.

8. Changes

This policy may be updated from time to time. The date above shows the latest version.
